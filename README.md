## 現在挑戦中（趣味・個人開発）

### ★学習Webアプリ

Microsoft 認定資格（AB-410）の練習問題を、**Microsoft Learn の公式ドキュメントだけを根拠に**複数の AI で作成・検証し、スマホで解ける学習アプリです。Claude Code で開発しています（ソースは非公開）。
新しい資格には紙の参考書がなく、公式の練習問題は量が限られ、Web の問題集は何を根拠に作られたのかが見えません。それなら、根拠のはっきりした問題を自分で作ろう、と始めました。

| 規模 | 約3週間でコミット152回、コード約4万行（うちテスト約1万3千行） |

#### 公式ドキュメントだけを根拠にした多段検証

1問ごとに、役割の違う AI を順に通します。

1. **素材選び**：問題の少ないシラバス項目を選び、Learn の文書から出題に使えるセクションを AI が判定する
2. **作成**：選んだセクションだけを根拠に、問題・選択肢・解説を作る。Learn 以外の情報が必要な問題は作らない
3. **照合**：正解を決める記述が、根拠以外の Learn の文書と食い違っていないかを確かめる
4. **解答**：作成役とは別の AI が実際に解き、正解が1つに決まるか、知識なしで消せる誤答がないかを見る
5. **校正**：問題文・選択肢・解説の言い回しを整える

指摘があれば作り直し、基準に届かない問題は保存しません。AI のモデルは、役割ごとに実際に比べて選んだものを、複数の会社から使い分けています。

#### 良い問題の「作り方」を種類として選べる

基礎・横断・ベストプラクティスの3種類を、画面から1問ずつ指定して作成を依頼できます。種類は単なるラベルではなく、定義・素材の集め方・検査までが一式になっています。たとえば横断問題は、2つ以上の製品の連携を問い、どちらか片方の知識だけでは解けず、制約条件で正解が1つに決まる問題だけを合格にします。

#### 使うほど育つ問題集

- **論点が重複しない**：同じ項目の過去の問題を作成役に渡し、保存の前にも似た問題がないかを調べる
- **偏らない**：問題の少ない項目や、まだ根拠に使っていないセクションを優先する
- **作成の過程がすべて見える**：素材・各チェックの結果・作り直しの経緯・費用を、1問ごとに確認できる

#### 根拠の文書の更新を検知する

公式ドキュメントは頻繁に更新されます。問題の根拠にしたセクションの本文を指紋（ハッシュ値）で記録しておき、変化があれば、問題に影響する変更かどうかを AI が判定します。ページの移動や削除も検知して、付け替え・改訂・破棄を提案します。改訂案の解説には「ドキュメント更新による変遷」を含め、仕様や呼び名の移り変わりそのものも学べるようにしています。

#### 学習記録とつながる出題

回答ごとに正誤と自信度（確信／迷い・勘）を記録し、自信を持って間違えた問題や、勘で当たった問題ほど出やすくします。通勤中にスマホで解けるよう、2タップでの解答、消去法、次の問題の先読み、ホーム画面への追加（PWA）に対応しています。
